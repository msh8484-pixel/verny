# VERNY 홈페이지 리디자인 기획 (v2)

작성일: 2026-07-12 · 기준 레퍼런스: https://p-31.kr/ (화이트 스니커즈 브랜드, Cafe24)

## 목표
- 홈페이지를 **형태(레이아웃)부터** 새로 만든다. 기존 소스(컴포넌트·양말/박스/행택 이미지·3D 뷰어)는 재활용.
- 시작점: **힉스필드 시네마틱 광고 영상**(19s, `public/hero-ad.mp4`)을 히어로에 사용.
- 무드: **화이트 미니멀**(P-31 기준) + **효과 강화** + VERNY 골드 포인트.
- 추후: **네이버쇼핑 연결(판매)** + **양말 신청서 폼**.

## 레퍼런스(P-31) 분석 요약
- 좌측 **고정 세로 내비**(로고+계정+메뉴+언어+CS/은행) — 스크롤 내내 고정.
- 극단적 화이트·큰 여백, 섹션마다 대형 브랜드 워드마크 반복.
- 구조: 제품 쇼케이스(화이트) → 제품 스토리(블랙 대비) → 룩북(라이프스타일 그리드) → 인스타 피드 → 푸터.
- 화이트↔블랙 극적 대비로 스토리텔링. 효과는 절제.

## 확정 결정
- **레이아웃 = 좌측 고정 세로 내비 + 우측 콘텐츠** (P-31식). 사용자 선택.
- 브랜드색: 화이트 베이스 + 잉크(`#111`) + **VERNY 골드 `#C9A84C`** 포인트.
- 타이포: **DM Serif Display**(디스플레이/로고) + 클린 산세리프(본문, Pretendard).

## 새 홈페이지 구조

좌측 고정 내비: `VERNY` 로고 → (제품 / 디테일 / 룩북 / 소개 / 구매) → 언어 → CS·연락 → (추후 계정/장바구니).

우측 콘텐츠(위→아래):
1. **히어로** — 광고 영상 풀블리드 + `VERNY` / "Trust Begins at the Detail" 오버레이 + 스크롤 큐 + [구매하기]/[신청].
2. **제품 쇼케이스(화이트)** — 컬러별(네이비·차콜·블랙) 중앙 대형 양말 컷 + 제품명 + 짧은 카피 + 구매버튼. 스크롤 핀/페이드.
3. **제품 스토리(다크 대비)** — 8:2 립조직 · 라이크라 커프밴드 · 28cm · 소재. 큰 세리프 + 매크로 컷. 화이트↔다크 전환.
4. **디테일 뷰어(인터랙티브)** — 기존 3D/4앵글 뷰어 + 컬러 선택. 회전·스왑·확대.
5. **룩북(화이트)** — 정장·구두 스타일링 에디토리얼 그리드. 호버 리빌·틸트.
6. **구매 & 신청** — 네이버쇼핑 연결 버튼 + 양말 신청서 폼(문의 폼 인프라 재사용). *추후 연동, 지금은 골격.*
7. **소셜/푸터** — 인스타 피드(선택) + 브랜드·연락처.
